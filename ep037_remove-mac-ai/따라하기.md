# 37화 RemoveMacAI 따라 하기 — 애플 인텔리전스 끄고 용량 되찾기

> 2026-10-17 기준, 공식 README 명령 원문이에요. 제 맥(macOS 27.0.1, Apple Silicon)은 애플 AI 관련 파일이 6.2GB였어요.
> 진짜 주소: https://github.com/omlahore/RemoveMacAI (MIT, 별 4,800+)

## 끄기 전에
- 시스템 설정을 바꾸는 프로그램이에요. **위 공식 저장소에서만** 받으세요. 비슷한 이름의 스크립트 묶음은 받지 마세요.
- 받아쓰기는 따로라서 꺼지지 않아요(README FAQ).
- 바꾸기 전에 전부 보여 주고, 전부 되돌릴 수 있어요.

## ① 설치 (둘 중 하나)
```sh
# Homebrew가 있으면
brew install omlahore/tap/removemacai
```
```sh
# 앱으로 쓰려면(최신 릴리스를 받아 SHA-256 확인 후 응용 프로그램에 넣음)
curl -fsSL https://raw.githubusercontent.com/omlahore/RemoveMacAI/main/install.sh | bash -s app
```
앱은 공증이 안 돼 있어서 처음 열 때 경고가 떠요. 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 「그래도 열기」를 누르세요.

## ② 먼저 보기만 하기
```sh
removemacai status        # 기능별로 켜져 있는지, 모델 용량이 얼마인지
removemacai clean         # 비울 수 있는 용량(이름을 붙여야 휴지통으로 옮겨요)
```

## ③ 끄기
```sh
removemacai off --keep writing-tools   # 쓰는 기능은 남기고 끄기(예: 글쓰기 도구)
removemacai                            # 전부 끄기(상태를 보여 준 뒤 끔)
```
설정 프로필을 시스템 설정에서 직접 승인해야 적용돼요(macOS 규칙).
`apply`·`undo`·`background`·`clean`은 바꿀 내용을 먼저 보여 주고 물어봐요. `--dry-run`을 붙이면 보여 주기만 해요.

## ④ 되돌리기
```sh
removemacai on       # 애플 인텔리전스만 다시 켜기
removemacai revert   # RemoveMacAI가 바꾼 것 전부 되돌리기
```

## 알아 둘 것
- 모델을 지워도 「설정 → 일반 → 저장 공간」 숫자는 바로 안 줄 수 있어요. macOS가 자기 일정에 맞춰 파일을 지워요(README FAQ).
- 「최대 12GB」는 보도·README 기준이에요. 맥마다 달라요.
- 휴지통으로 옮긴 파일은 휴지통을 비워야 용량이 돌아와요.
