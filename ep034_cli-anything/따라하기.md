# 34화 CLI-Anything 따라 하기 — 리브레오피스 창 안 열고 문서 만들기

> 2026-10-15 맥(macOS, Apple Silicon)에서 직접 돌린 명령이에요. 4줄에 7.4초 걸렸고(PDF 내보내기 7.1초), 창은 한 번도 안 열렸어요.
> 버전: cli-anything-hub 0.4.1 · cli-anything-libreoffice 1.0.1 · LibreOffice 24.8.2.1

## 준비
- 리브레오피스는 따로 설치해야 해요: https://www.libreoffice.org
- 파이썬 3가 있어야 해요.

## ① 설치
```bash
pip install cli-anything-hub
cli-hub install libreoffice
```

## ② 문서 만들고 PDF로 내보내기 (4줄)
```bash
cli-anything-libreoffice document new --type writer -n 회의록 -o 회의록.lo-cli.json
cli-anything-libreoffice --project 회의록.lo-cli.json writer add-heading -t "깃냥이 34화 회의록" -l 1
cli-anything-libreoffice --project 회의록.lo-cli.json writer add-list -i "앱 창 안 열고 문서 만들기" -i "PDF로 내보내기" -i "걸린 시간 재기" --style number
cli-anything-libreoffice --project 회의록.lo-cli.json export render 회의록.pdf -p pdf --overwrite
```

## 주의
- **사용 통계가 기본으로 켜져 있어요.** 끄려면 먼저 `export CLI_HUB_NO_ANALYTICS=1`을 실행하세요(실측 때도 끄고 했어요).
- `--style number`로 시켰는데 PDF에는 번호 대신 점 목록으로 나왔어요(1.0.1 기준).
