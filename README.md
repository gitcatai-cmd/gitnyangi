# 깃냥이 자료실

유튜브 **[깃냥이](https://www.youtube.com/@깃냥이)** 영상에서 직접 해 본 것을 그대로 따라 할 수 있게 모아 둔 곳이에요.
누구나 받을 수 있어요. 구독·댓글 같은 조건은 없어요.

## 편마다 들어 있는 것
| 파일 | 내용 |
|---|---|
| `따라하기.md` | 설치·실행 명령을 순서대로(영상 찍은 날 기준, 공식 문서 원문) |
| `체크리스트.md` | 놓치면 안 되는 할 일을 순서대로(공식 안내 원문 링크) |
| `실측.csv` / `실측.md` | 우리 맥·우분투에서 직접 잰 속도·메모리·한국어 정확도 |
| `라이선스.md` | 앱·모델을 회사나 돈 버는 데 써도 되는지(원문 링크·확인 날짜) |
| 그 편에 따라 하나 | 프롬프트 모음 / ComfyUI 워크플로 json / 오류 해결 표 / 예제 파일 |

- 모델 파일은 넣지 않아요. 공식 주소만 적어 둬요.
- 남이 만든 프롬프트·코드는 옮기지 않아요. 원래 저장소 주소를 적어요.
- 우리가 시험한 기기와 날짜를 함께 적어요. 다른 컴퓨터에서는 결과가 다를 수 있어요.
- 법률 자문이 아니에요. 라이선스는 원문을 꼭 직접 확인하세요.
