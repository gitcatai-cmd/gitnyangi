# 42화 클로드 디자인 닫히기 전 할 일 체크리스트

> 2026-10-17 기준, 앤트로픽 공식 도움말 「Migrate from standalone Claude Design to Claude」를 정리했어요.
> 원문: https://support.claude.com/en/articles/17440474-migrate-from-standalone-claude-design-to-claude
> 안내가 바뀔 수 있으니 날짜가 가까워지면 원문을 한 번 더 확인하세요.

## 언제
- 따로 있던 사이트 **claude.ai/design 은 2026년 12월 14일에 닫혀요.** 그 뒤로 이 주소는 Claude로 넘어가요.
- 그때까지는 원래 사이트를 그대로 쓸 수 있어요.
- 새 디자인·디자인 시스템·슬라이드는 이제 Claude 안에서 아티팩트로 만들어져요.

## 체크리스트
- [ ] **1. 프로젝트 목록 적기** — Claude의 Artifacts 화면에 원래 사이트 프로젝트가 60개까지 보여요. 남길 것과 버릴 것을 먼저 고르세요.
- [ ] **2. 프로젝트 하나씩 내보내기** — 프로젝트는 저절로 안 옮겨져요.
  1. 원래 사이트에서 프로젝트 열기
  2. Share → Project HTML (슬라이드는 More formats and apps 안에 있어요)
  3. Project archive 그대로 두고 Export
  - 모든 파일이 든 .zip 이 받아져요. 무료이고 사용량에 들어가지 않아요. 한 번에 하나씩만 돼요.
- [ ] **3. 디자인 시스템 옮기기** — 이것도 저절로는 안 되고, 직접 눌러야 해요.
  1. Claude의 Artifacts 화면 열기
  2. 배너의 Migrate team design systems (배너를 닫았다면 오른쪽 위 Claude Design 메뉴)
  3. Migrate 확인 (개인 요금제는 확인 없이 바로 시작)
  4. Migrated 칸에서 결과 확인
  - 한 번 누르면 조직 안 디자인 시스템이 전부 옮겨져요. 비어 있거나 기본 테마로 만든 것은 빠져요.
  - Couldn't be migrated 에 뜨면 그 줄의 Fix in Claude Design Standalone → Check 로 걸리는 파일을 고치고 다시 옮기세요. uploads 폴더에 중복 파일이 많아요.
- [ ] **4. 채팅·댓글 따로 남기기** — 클로드와 나눈 채팅, 프로젝트·디자인 시스템 댓글은 **옮겨지지 않고 사이트가 닫힌 뒤 지워져요.** 결정한 이유 같은 건 문서로 복사해 두세요.
- [ ] **5. 공개 링크 바꾸기** — 공개한 프로젝트 링크는 12월 14일에 끊겨요. 블로그·노션·포트폴리오에 붙인 주소가 있으면 미리 바꿔 두세요.
- [ ] **6. (팀·엔터프라이즈 관리자) 설정 확인** — Organization settings → Artifacts 에서 Artifacts·Design systems·Design and Slides 가 켜져 있어야 옮길 수 있어요. 엔터프라이즈는 Design systems·Design and Slides 기본값이 꺼짐이에요. 데이터 보존 0(ZDR) 조직은 옮기기가 안 되니 꼭 내보내기로 받아 두세요.

## 자주 묻는 것
- **무료 요금제도 되나요?** Claude Design 은 Free·Pro·Max·Team·Enterprise 모두 쓸 수 있어요.
- **원래 것은 언제까지 남나요?** 12월 14일까지 그대로 돼요. 그 뒤 데이터 보존 정책에 따라 지워져요.
- **프로젝트를 옮기는 기능은요?** 공식 안내에 「곧 나온다(coming soon)」고만 적혀 있어요. 기다리지 말고 내보내기로 받아 두는 게 안전해요.

법률·계약 조언이 아니에요. 회사 계정이면 관리자 안내를 먼저 따르세요.
